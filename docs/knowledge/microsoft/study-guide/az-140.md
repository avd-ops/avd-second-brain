# AZ-140 study guide

**Bottom line:** half the exam is infrastructure (networking, storage, host pools, images). Know
the roles each feature needs, because "it's configured but doesn't work" questions usually come down
to a missing role assignment.

Back to the [study guide](README.md). The official skills outline is the
[AZ-140 study guide](https://learn.microsoft.com/credentials/certifications/resources/study-guides/az-140) (updated 2026-07-20); the domains and weights below follow it, and the
notes under them are ours. Each domain names the [avd-assess](https://github.com/avd-ops/avd-assess)
map pillars that cover the same ground, and each objective links where the
[avd-landing-zone](https://github.com/avd-ops/avd-landing-zone) builds it.

## What changed in recent years

If you studied AZ-140 a few years ago, start here. This list comes from the product's history, not
from comparing outlines line by line.

- Names: Microsoft Entra ID, Entra Domain Services, App Control for Business, Azure Local.
- Entra-joined session hosts as a first-class option, Entra single sign-on (`enablerdsaadauth:i:1`),
  passwordless and smart card sign-in, and the Virtual Machine User Login role.
- Azure Files with Entra Kerberos for hybrid identities, alongside AD DS and Entra Domain Services.
- Networking: Private Link for AVD (connection, feed and global sub-resources), RDP Shortpath for
  public networks with TURN relay, RDP Multipath.
- Autoscale scaling plans, also for personal host pools (start, stop, hibernate), with the
  Desktop Virtualization Power On Off Contributor role.
- App attach: MSIX or Appx in CimFS images, assigned to users directly and shared across host
  pools. It replaces MSIX app attach.
- Monitoring on Azure Monitor Agent with a data collection rule (the `microsoft-avdi-` prefix) for
  AVD Insights, replacing the Log Analytics agent.
- Security: Trusted Launch by default, confidential VMs, Defender for Endpoint VDI onboarding,
  Controlled Folder Access.
- Clients and apps: Windows App, multimedia redirection, Universal Print, new Teams with the
  WebRTC Redirector Service, OneDrive on multi-session.
- Licensing: RDS CALs for Windows Server hosts, per-user access pricing for external users.

## Objectives

### Plan and implement an Azure Virtual Desktop infrastructure (40 to 45%)

Map pillars in avd-assess: `networking-azure`, `profiles`, `capacity`, `images` ([pillars.yaml](https://github.com/avd-ops/avd-assess/blob/main/pillars.yaml)).

#### Networking

- **Know:** Size bandwidth per user type. RDP Shortpath for managed networks uses direct UDP to the session host (port 3390) over VPN or ExpressRoute; Shortpath for public networks uses STUN for a direct path and TURN relay (UDP 3478) when direct fails. RDP Multipath adds extra paths for resilience. QoS tags RDP traffic with DSCP. Private Link uses three sub-resources: connection (per host pool), feed (per workspace) and global (one workspace for initial feed discovery for all users), plus the privatelink.wvd.microsoft.com DNS zone. Troubleshoot with the required URL check tool and Connection Information in the client.
- **Trap:** Reverse connect means session hosts need no inbound ports. Only outbound to the required URLs and service tags. A question that opens inbound 3389 is a distractor.
- **See it built:** [network.bicep](https://github.com/avd-ops/avd-landing-zone/blob/master/bicep/modules/network.bicep), [privateDns.bicep](https://github.com/avd-ops/avd-landing-zone/blob/master/bicep/modules/privateDns.bicep)

#### Storage for user data

- **Know:** Azure Files premium (FileStorage account) or Azure NetApp Files for profiles at scale. Azure Files needs identity-based auth: AD DS, Entra Domain Services or Entra Kerberos for hybrid identities. Share-level RBAC: Storage File Data SMB Share Contributor for users, Elevated Contributor for admins; then NTFS permissions. ANF needs a delegated subnet, a capacity pool and an AD connection.
- **Trap:** Share-level RBAC alone is not enough. NTFS permissions still decide access to each folder. Users get Modify on this folder only, CREATOR OWNER gets subfolders and files.
- **See it built:** [storage.bicep](https://github.com/avd-ops/avd-landing-zone/blob/master/bicep/modules/storage.bicep), [FSLogix profiles](../../fslogix/README.md)

#### Plan host pools and session hosts

- **Know:** Pooled vs personal; breadth-first spreads users, depth-first fills one host before the next (best with autoscale to save cost). Windows 11 Enterprise multi-session for pooled desktops. Size by workload (light, medium, heavy, power) and max session limit. Separate resource groups for service objects and session hosts.
- **Trap:** Personal host pools ignore load balancing; assignment is automatic or direct. The validation environment flag gets service updates first.
- **See it built:** [controlPlane.bicep](https://github.com/avd-ops/avd-landing-zone/blob/master/bicep/modules/controlPlane.bicep)

#### Implement host pools and session hosts

- **Know:** Portal, PowerShell (Az.DesktopVirtualization), CLI, ARM and Bicep. Session hosts register with a registration token, valid from 1 hour to 27 days. Licensing: Windows client multi-session needs M365 E3/E5/A3/A5/F3/Business Premium or Windows E3/E5/A3/A5; Windows Server hosts need RDS CALs and a license server. Per-user access pricing covers external users.
- **Trap:** RDS CALs are only for Windows Server session hosts. A Windows 11 multi-session question that offers RDS CALs is wrong.
- **See it built:** [sessionHosts.bicep](https://github.com/avd-ops/avd-landing-zone/blob/master/bicep/modules/sessionHosts.bicep), [Register-AvdAgent.ps1](https://github.com/avd-ops/avd-landing-zone/blob/master/scripts/sessionhost/Register-AvdAgent.ps1)

#### Session host images

- **Know:** Manual build then Sysprep /generalize /oobe /shutdown, capture to Azure Compute Gallery. Azure VM Image Builder automates it with customizers. Gallery has image definitions (generation, security type) and versions with replication regions, end-of-life dates and exclude-from-latest. Patch the image, publish a new version, roll hosts.
- **Trap:** Trusted Launch needs a Gen2 image in Compute Gallery with a Trusted Launch security type. Managed images and Gen1 images do not work. Do not domain join or install the AVD agent before capture.
- **See it built:** [main.bicep](https://github.com/avd-ops/avd-landing-zone/blob/master/bicep/images/main.bicep), [gallery.bicep](https://github.com/avd-ops/avd-landing-zone/blob/master/bicep/images/modules/gallery.bicep), [images.md](https://github.com/avd-ops/avd-landing-zone/blob/master/docs/images.md)

### Plan and implement identity and security (15 to 20%)

Map pillars in avd-assess: `identity`, `security-posture`, `endpoint-protection` ([pillars.yaml](https://github.com/avd-ops/avd-assess/blob/main/pillars.yaml)).

#### Identity integration

- **Know:** AD DS (hybrid), Entra joined (cloud), or Entra Domain Services. Entra-joined hosts need users to have Virtual Machine User Login (or Administrator Login) on the VMs. AVD RBAC roles: Desktop Virtualization Contributor, Reader, User Session Operator, Host Pool Contributor, Application Group Contributor, Power On Contributor, Power On Off Contributor. Conditional Access targets the Azure Virtual Desktop app (and Windows Cloud Login with SSO). SSO via the RDP property enablerdsaadauth:i:1.
- **Trap:** Assigning a user to an app group lets them see the resource. It does not let them sign in to an Entra-joined host without the VM login role.
- **See it built:** [Identity and Entra](../../identity/README.md)

#### Security

- **Know:** Defender for Cloud on session hosts; Defender Antivirus exclusions for FSLogix VHDs; Defender for Endpoint with the VDI onboarding script for non-persistent hosts. NSGs, UDRs and Azure Firewall with the WindowsVirtualDesktop FQDN tag. Admin access through Bastion or JIT. App Control for Business, Controlled Folder Access. Trusted Launch (Secure Boot, vTPM) and confidential VMs.
- **Trap:** JIT opens an inbound port for a time window and needs Defender for Servers Plan 2. Bastion opens nothing to the internet. Pick by what the question forbids.
- **See it built:** [bastionDeveloper.bicep](https://github.com/avd-ops/avd-landing-zone/blob/master/bicep/modules/bastionDeveloper.bicep), [sessionHosts.bicep](https://github.com/avd-ops/avd-landing-zone/blob/master/bicep/modules/sessionHosts.bicep)

### Plan and implement user environments and apps (20 to 25%)

Map pillars in avd-assess: `profiles`, `endpoints`, `app-delivery`, `protocol` ([pillars.yaml](https://github.com/avd-ops/avd-assess/blob/main/pillars.yaml)).

#### FSLogix

- **Know:** Profile Container: `HKLM\SOFTWARE\FSLogix\Profiles` with Enabled=1 and VHDLocations; VHDX, dynamic, default size 30 GB. ODFC container for Office data only. Cloud Cache replaces VHDLocations with CCDLocations, listing more than one provider for resilience. Application masking uses rule (.fxr) and assignment (.fxa) files from the Rule Editor.
- **Trap:** Never set VHDLocations and CCDLocations together. Add local admin accounts to the FSLogix Profile Exclude List group.
- **See it built:** [Set-FSLogixConfiguration.ps1](https://github.com/avd-ops/avd-landing-zone/blob/master/scripts/sessionhost/Set-FSLogixConfiguration.ps1), [FSLogix profiles](../../fslogix/README.md)

#### User experience and client settings

- **Know:** Windows App and Remote Desktop clients, web client; deploy by MSI, Intune or Store. Device, clipboard and drive redirection through RDP properties on the host pool. Multimedia redirection needs the host component and the browser extension. Universal Print. Session time limits by Intune or GPO. Start VM on Connect needs the AVD service principal to have Desktop Virtualization Power On Contributor.
- **Trap:** RDP properties are set on the host pool, not the workspace or app group. Start VM on Connect failing is nearly always the missing role.
- **See it built:** [controlPlane.bicep](https://github.com/avd-ops/avd-landing-zone/blob/master/bicep/modules/controlPlane.bicep)

#### Apps on session hosts

- **Know:** App groups: one desktop group and any number of RemoteApp groups per host pool, registered to a workspace in the same region. Microsoft 365 Apps with shared computer activation; OneDrive per-machine install; Teams with the Remote Desktop WebRTC Redirector Service. App attach packages MSIX or Appx into CimFS or VHDX images with msixmgr, and is assigned to users directly and to many host pools.
- **Trap:** An app group not registered to a workspace never shows in the feed, even with users assigned.
- **See it built:** [controlPlane.bicep](https://github.com/avd-ops/avd-landing-zone/blob/master/bicep/modules/controlPlane.bicep)

### Monitor and maintain an Azure Virtual Desktop infrastructure (10 to 15%)

Map pillars in avd-assess: `monitoring`, `scaling`, `reliability` ([pillars.yaml](https://github.com/avd-ops/avd-assess/blob/main/pillars.yaml)).

#### Monitor and manage

- **Know:** Diagnostic settings on host pool and workspace send WVDConnections, WVDErrors, WVDCheckpoints and WVDAgentHealthStatus to Log Analytics. AVD Insights needs Azure Monitor Agent on hosts with a data collection rule named with the microsoft-avdi- prefix. Autoscale scaling plans have ramp-up, peak, ramp-down and off-peak phases with capacity threshold and minimum host percentage; personal host pools can start, stop or hibernate.
- **Trap:** Force logoff with a warning message is set in the ramp-down phase. Scaling plans need the Power On Off Contributor role for the AVD service principal.
- **See it built:** [monitoring.bicep](https://github.com/avd-ops/avd-landing-zone/blob/master/bicep/modules/monitoring.bicep), [user-connection.kql](https://github.com/avd-ops/avd-landing-zone/blob/master/scripts/ops/kql/user-connection.kql)

#### Updates, backup and DR

- **Know:** Update the image and replace hosts, or patch in place with Update Manager. Pooled DR: a secondary host pool in another region plus profile replication (Cloud Cache across regions or storage replication). Personal DR: Azure Site Recovery. Back up Azure Files shares and personal VMs with Azure Backup; images through gallery replication.
- **Trap:** The AVD service metadata is managed by Microsoft. Your DR plan covers session hosts, profiles and images, not the control plane.
- **See it built:** [backup.bicep](https://github.com/avd-ops/avd-landing-zone/blob/master/bicep/modules/backup.bicep), [Invoke-AvdHostRotation.ps1](https://github.com/avd-ops/avd-landing-zone/blob/master/scripts/ops/Invoke-AvdHostRotation.ps1)

## Practice questions

Pick an answer before you open it. Then read why the others are wrong.

### Infrastructure

**Q1.** Users connect from head office over ExpressRoute. You want RDP to use a direct UDP path from the client to the session host over the private connection. What do you configure?

- A. Azure Private Link for Azure Virtual Desktop
- B. RDP Shortpath for public networks
- C. RDP Shortpath for managed networks
- D. A QoS policy with DSCP 46

<details><summary>Answer</summary>

**C.** Shortpath for managed networks gives a direct UDP flow over private connectivity (VPN or ExpressRoute) to the host. The public networks variant uses STUN or a TURN relay across the internet. Private Link changes where the service is reached, not the transport. QoS only marks traffic.

</details>

**Q2.** You deploy Private Link for Azure Virtual Desktop and block public access. Users cannot discover their feed. Which private endpoint is missing if the feed and connection endpoints already exist?

- A. global, on one workspace for all users
- B. blob, on the profile storage account
- C. feed, on every application group
- D. hostpool

<details><summary>Answer</summary>

**A.** Initial feed discovery uses the global sub-resource. You create it once, on a dedicated workspace, and it serves all workspaces. Feed is per workspace, connection is per host pool.

</details>

**Q3.** You need SMB storage for FSLogix profiles for 800 concurrent users with consistent low latency and the least management effort. What do you recommend?

- A. Azure Files on a standard general-purpose v2 account, hot tier
- B. A shared Azure managed disk
- C. Azure Files premium on a FileStorage account
- D. Premium block blob storage

<details><summary>Answer</summary>

**C.** Microsoft recommends Azure Files premium (or Azure NetApp Files for large estates) for production profile containers. Standard shares have lower IOPS per share, blob is not SMB, and shared disks need a cluster file system.

</details>

**Q4.** A pooled host pool uses a scaling plan to deallocate idle hosts. Which load-balancing algorithm lets the most hosts stay off during the day?

- A. Breadth-first
- B. Persistent
- C. Depth-first
- D. Round robin

<details><summary>Answer</summary>

**C.** Depth-first fills one host to the max session limit before using the next, so unused hosts can stay deallocated. Breadth-first spreads users across every running host.

</details>

**Q5.** You built a Windows 11 multi-session VM as a golden image. What do you run before capturing it as a generalized image?

- A. Stop the VM from the portal without Sysprep
- B. sysprep /generalize /oobe /shutdown
- C. Install the AVD agent and boot loader, then capture
- D. Join the domain, then Sysprep

<details><summary>Answer</summary>

**B.** Generalize with Sysprep and shut down, then capture. Domain join and the AVD agent happen when each session host is created from the image.

</details>

**Q6.** New session hosts must use Trusted Launch and a custom image. Where must the image be stored?

- A. An Azure Compute Gallery image definition, Gen2, with a Trusted Launch security type
- B. A VHD in a storage account
- C. A managed image, Gen1
- D. Any managed image if Secure Boot is turned on after deployment

<details><summary>Answer</summary>

**A.** Trusted Launch needs a Gen2 image from Compute Gallery whose definition supports Trusted Launch. Managed images and Gen1 images are not supported.

</details>

**Q7.** Employees will use Windows 11 Enterprise multi-session session hosts. Which license meets the access requirement for each user?

- A. Microsoft 365 E3
- B. Windows Server Datacenter
- C. An RDS CAL per user
- D. No license; AVD access is free

<details><summary>Answer</summary>

**A.** Windows client multi-session needs an eligible license such as Microsoft 365 E3/E5/A3/A5/F3/Business Premium or Windows E3/E5. RDS CALs apply to Windows Server session hosts.

</details>

**Q8.** You script session host deployment for a month-long rollout and want one registration token for the whole run. What is the longest expiry you can set?

- A. 1 hour
- B. 24 hours
- C. 27 days
- D. 90 days

<details><summary>Answer</summary>

**C.** A host pool registration token can be valid from one hour up to 27 days.

</details>


### Identity and security

**Q9.** Session hosts are Entra joined. Users are assigned to the desktop app group and see the desktop, but sign-in fails. What is missing?

- A. Contributor on the workspace
- B. Desktop Virtualization User on the host pool
- C. Hybrid join of the session hosts
- D. Virtual Machine User Login on the session host VMs or their resource group

<details><summary>Answer</summary>

**D.** For Entra-joined hosts, users need Virtual Machine User Login (or Administrator Login) on the VMs. App group assignment only publishes the resource.

</details>

**Q10.** Help desk staff must see user sessions, send messages and log users off, but not change host pools. Which role do you assign?

- A. Virtual Machine Contributor
- B. Desktop Virtualization User Session Operator
- C. Desktop Virtualization Contributor
- D. Desktop Virtualization Reader

<details><summary>Answer</summary>

**B.** User Session Operator manages sessions without granting changes to host pools or app groups.

</details>

**Q11.** You want MFA on every Azure Virtual Desktop connection. Which cloud app does the Conditional Access policy target?

- A. Azure Virtual Desktop
- B. Microsoft Azure Management
- C. Office 365
- D. Microsoft Intune

<details><summary>Answer</summary>

**A.** Target Azure Virtual Desktop (and also Windows Cloud Login when Entra SSO is on). Azure Management covers the portal and ARM, not session connections.

</details>

**Q12.** Admins need RDP to session hosts that have no public IP, and no inbound port may open to the internet, even temporarily. What do you use?

- A. An NSG rule allowing 3389 from the admins' home IPs
- B. Azure Bastion
- C. Just-in-time VM access
- D. A public load balancer with inbound NAT

<details><summary>Answer</summary>

**B.** Bastion brokers RDP over TLS from the portal or native client with no inbound internet port on the VM. JIT still opens a port for a window.

</details>

**Q13.** Pooled hosts are rebuilt from the image every week. Defender for Endpoint shows many duplicate devices. What fixes it?

- A. Use Defender Antivirus only
- B. Onboard each host by hand after deployment
- C. Onboard with the VDI onboarding script set for a single entry per device
- D. Turn off Defender for Endpoint on pooled hosts

<details><summary>Answer</summary>

**C.** The non-persistent VDI onboarding method keeps one device entry per host name across rebuilds.

</details>


### User environments and apps

**Q14.** You configure FSLogix Cloud Cache with profile storage in two regions. Which registry value lists the storage locations?

- A. VHDLocations, with both shares
- B. ProfileType
- C. VHDLocations and CCDLocations, one share each
- D. CCDLocations, with both providers

<details><summary>Answer</summary>

**D.** Cloud Cache uses CCDLocations with more than one provider. It replaces VHDLocations; setting both is unsupported.

</details>

**Q15.** The local administrator account must not get a profile container. What do you do?

- A. Add the account to the FSLogix Profile Exclude List group
- B. Remove Everyone from the FSLogix Profile Include List
- C. Set Enabled=0 for that user in HKCU
- D. Grant the account Deny on the share

<details><summary>Answer</summary>

**A.** Members of the FSLogix Profile Exclude List local group are skipped. Exclude wins over include.

</details>

**Q16.** Users need to create and use their own profile folders on an Azure Files share. Which share-level role do you give the user group?

- A. Storage File Data SMB Share Reader
- B. Storage File Data SMB Share Elevated Contributor
- C. Storage File Data SMB Share Contributor
- D. Storage Account Contributor

<details><summary>Answer</summary>

**C.** Contributor gives read, write and delete over SMB. Elevated Contributor adds changing NTFS permissions and is for admins. Storage Account Contributor is a management-plane role.

</details>

**Q17.** Teams calls are slow on session hosts and audio is processed on the host. What component enables media optimization on the host?

- A. FSLogix ODFC container
- B. Remote Desktop WebRTC Redirector Service
- C. Universal Print connector
- D. Multimedia redirection extension

<details><summary>Answer</summary>

**B.** The WebRTC Redirector Service, with Teams installed for VDI, offloads calls to the client device. Multimedia redirection is for browser video.

</details>

**Q18.** You package an MSIX app for app attach and want the best sign-in performance. Which disk image format do you create with msixmgr?

- A. VHD
- B. CimFS (.cim)
- C. VHDX
- D. ZIP

<details><summary>Answer</summary>

**B.** CimFS images mount faster and use less overhead than VHD or VHDX. msixmgr can create all three.

</details>

**Q19.** Start VM on Connect is turned on for a personal host pool, but users get an error when their VM is deallocated. What is the most likely cause?

- A. The host pool uses depth-first
- B. The Azure Virtual Desktop service principal lacks Desktop Virtualization Power On Contributor
- C. Users are missing Virtual Machine Contributor
- D. The workspace is in a different region

<details><summary>Answer</summary>

**B.** The service principal needs the Power On Contributor role on the subscription or resource group holding the VMs.

</details>

**Q20.** Users are assigned to a new RemoteApp app group but the apps do not appear in their client. The host pool is healthy. What is wrong?

- A. The app group is not registered to a workspace
- B. The host pool max session limit is reached
- C. Start VM on Connect is off
- D. The users need Virtual Machine User Login

<details><summary>Answer</summary>

**A.** Only app groups registered to a workspace appear in the feed.

</details>


### Monitor and maintain

**Q21.** AVD Insights shows connection data but no session host performance counters. Diagnostic settings are on. What is missing?

- A. A data collection rule with the microsoft-avdi- prefix and Azure Monitor Agent on the hosts
- B. An action group
- C. Diagnostic settings on the application groups
- D. A second Log Analytics workspace

<details><summary>Answer</summary>

**A.** Host performance data comes from Azure Monitor Agent through a data collection rule. Insights looks for a DCR named with the microsoft-avdi- prefix.

</details>

**Q22.** Which Log Analytics table do you query to list each user's connection start and end?

- A. WVDCheckpoints
- B. WVDAgentHealthStatus
- C. WVDErrors
- D. WVDConnections

<details><summary>Answer</summary>

**D.** WVDConnections holds connection state changes per user and session host.

</details>

**Q23.** In a scaling plan, where do you set users to be logged off after a warning so hosts can shut down in the evening?

- A. Off-peak capacity threshold
- B. Ramp-up
- C. Peak
- D. Ramp-down

<details><summary>Answer</summary>

**D.** Ramp-down holds the force logoff setting, the wait time and the message.

</details>

**Q24.** A pooled host pool must survive a region outage, and users must keep their profiles. What do you design?

- A. A secondary host pool in another region with FSLogix Cloud Cache writing to storage in both regions
- B. A larger max session limit in the primary region
- C. Azure Site Recovery for every pooled session host
- D. Geo-redundant backup of the host pool object

<details><summary>Answer</summary>

**A.** Pooled hosts are stateless; you rebuild or keep a second host pool, and replicate profiles. Site Recovery fits personal desktops.

</details>
